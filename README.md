## Snake Game

### Objective
The objective of the game is to control a snake to eat food and grow in length. The game ends when the snake collides with itself or the walls.

### Rules
1. Use the arrow keys to control the direction of the snake.
2. The snake grows in length each time it eats food.
3. The game ends if the snake collides with itself or the walls.

### How to Run the Game
1. Ensure you have Python installed on your system.
2. Install the Pygame library using the command: `pip install pygame`
3. Run the game by executing the following command: `python src/snake.py`

### Audio Files
The game includes the following audio files:
1. `assets/eat.mp3`: Sound played when the snake eats food.
2. `assets/game_over.mp3`: Sound played when the game is over.
